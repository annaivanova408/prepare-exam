# Веб-платформа подготовки к экзамену

Проект собирает материалы из тематических папок, создает отдельные `glossary.md` по каждой теме, и статическую веб-платформу (темы → определения → тест → карточки).

## Куда класть материалы

Материалы кладутся в корень проекта в папки вида:

```text
Тема 1. Название темы/
Тема 2. Название темы/
```

Поддерживаются файлы `.docx`, `.doc`, `.pptx`, `.pdf`, `.txt`, `.md`. Одна папка считается одной темой.

## Как сгенерировать глоссарии и данные для веб

```bash
/Users/annaivanova/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 scripts/generate_materials.py
```

После запуска появятся:

- тематические глоссарии: `Тема .../glossary.md`;
- данные веб-платформы: `data/topics.json`;
- извлеченные тексты для проверки: `data/extracted_materials.json`;
- (опционально, если вам нужен старый файл): `exam_preparation_materials.docx` может остаться от предыдущих запусков.

Если определения/ответы на вопросы в материалах не встречаются явно, генератор ставит `требует дополнения`.

## Как запустить веб-платформу

Сначала сгенерируйте данные командой выше, затем:

```bash
docker compose up --build
```

Платформа будет доступна по адресу:

```text
http://localhost:8080
```

Важно для Safari: не открывайте `web/index.html` двойным кликом как файл. Safari блокирует загрузку `data/topics.json` из `file://`, поэтому страницу нужно открывать через локальный сервер, например по адресу выше.

Для быстрой проверки без Docker можно запустить из корня проекта:

```bash
/Users/annaivanova/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 -m http.server 8090
```

И открыть:

```text
http://127.0.0.1:8090/web/index.html
```

## Как обновлять материалы

1. Добавьте или замените файлы в нужной тематической папке.
2. Запустите `scripts/generate_materials.py`.
3. Перезапустите Docker:

```bash
docker compose up --build
```

## Структура проекта

```text
scripts/generate_materials.py        генерация глоссариев по темам и `data/topics.json`
web/index.html                       интерфейс платформы
web/styles.css                       стили платформы
web/app.js                           логика тем, поиска, тестов и карточек
data/topics.json                     темы, определения, тесты, карточки, источники
exam_preparation_materials.docx      (опционально) старый итоговый Word-документ
Тема .../glossary.md                 отдельный глоссарий темы
Dockerfile                           сборка веб-платформы
docker-compose.yml                   запуск веб-платформы
```

## Добавление новых тем и терминов

Создайте новую папку `Тема N. ...`, положите туда материалы и снова запустите генератор. Данные веб-платформы строятся из JSON, поэтому новые темы, термины, вопросы, задания и материалы появятся после регенерации.
